# Exercício 01 — Introdução ao Blazor

Aplicação web criada com Blazor e .NET 10. A interface está em português e inclui as páginas Início, Contador e Previsão do tempo.

## Requisitos

- .NET 10 SDK

## Executar

Na pasta do projeto:

```bash
dotnet watch run
```

O terminal exibirá o endereço local da aplicação. O `dotnet watch` recompila as alterações compatíveis enquanto o projeto está em execução.
